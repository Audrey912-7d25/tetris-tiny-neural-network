# tetris-tiny-neural-network
still being made! not alot to see here so really just like do not look at this while I make it :3

For the current version of this script simply download the appimage, make it executable with

chmod +x "the downloaded executable filename"

and then run it! with ./"filename"

If you wish to run it outside of the appimage simply download all the sourcecode and do cargo run --release in the main directory

worst case scenario try without --release if there are any bugs and please report them!

Current version of the program run 200k networks on a single core to benchmark how fast all of the games can get done! is dependant though on the network itself and what decisions it makes so results may vary on speed.
