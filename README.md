# tetris-tiny-neural-network
still being made! not alot to see here so really just like do not look at this while I make it :3

For the current version of this script simply download the appimage, make it executable with

chmod +x "the downloaded executable filename"

and then run it! with ./"filename"

If you wish to run it outside of the appimage simply download all the sourcecode and attach to the python environment (if that works) and then run main.py

Worst case scenario all of the packages necessary are listed at the top of main.py and you can just install the pip packages listed there.

Current version of the program starts at trying out 512 games on the same network five times and then doubles it six times! this is to gauge the accuracy of the network as the number of games increases and to benchmark the number of games a single core on your machine can do.
